# Release v1 (21 Oct 2026): quantum and classical physics-informed networks for laser-pulse thermoelasticity

Everything in this archive was executed on one Apple M2 Max (12 cores, CPU only) with Python 3.12.5, PyTorch 2.9.1,
NumPy 2.5.1, SciPy 1.16.3 (float64 / complex128 exact statevector simulation). Thread settings per launcher are declared in
the launcher scripts (OMP_NUM_THREADS: E1, learning-rate selection, E3 main queue, secondary wave speeds 3; E1b, x_min
ablation, auxiliary E3 queue 2; E4 evaluator 4).

## Contents
- analysis/qpinn_local.py          training code (models VQC / MLP / Fourier-feature MLP / reference MLP, losses, optimisers, metrics, CLI)
- analysis/ground_truth.py         corrected closed-form exact fields (self-test: `python3 ground_truth.py`)
- analysis/noise_eval.py, run_e4.py   E4 finite-shot / depolarising evaluation of saved checkpoints
- analysis/run_*.sh, select_lrs.py    launchers (E1, E1b, learning-rate selection, x_min ablation, E3 main + auxiliary queue, secondary speeds)
- analysis/functional_count.py     perturbation audit of output-affecting circuit coordinates
- analysis/family_equivalence.py   depth-2 output-family equivalence check
- analysis/closed_form_corrected.py, laplace_ref.py, fd_ref.py, check_corrected.py   verification of the exact solution
- analysis/make_results_package.py, make_runs_all.py, make_code_bundle.sh   table / figure / record generators
- analysis/results/                every per-run record (JSON: errors, settings, loss history, L-BFGS closure count) and the
                                   trained checkpoint of every run (.pt state dictionaries); subdirectories e1, fmatch (E1b),
                                   lrsel, fmatch_lrsel, e3_lrsel_data (learning-rate candidates), ablation, ablation_repro, e3,
                                   gamma; e2_exp_g9.json (E2 aggregate variances), e4_noise.json (corrected E4 records).
                                   Directories and files named *_superseded_* are discarded earlier launches (wrong rates,
                                   superseded field mapping / parametrisation); they are kept for provenance and are not used
                                   by any table.
- analysis/logs/                   execution logs of every launcher, queue dispatcher outputs, the initial-rate weight
                                   ablation (logs/variants) and the pilot / diagnostic runs
- manuscript_source/              manuscript v7 sources (v6 + repository address; main.tex, supp.tex, refs.bib, figures/), the compiled PDFs and the executed
                                   TeXcount reports (texcount_v6_main.txt: `texcount -sum -merge main.tex`, whose %TC:ignore
                                   boundaries exclude the title block and everything after Conclusions; texcount_v6_supp.txt;
                                   texcount_v6_abstract.txt from the abstract environment alone), and previous_versions/ with the
                                   v5 and v6 PDFs and sources reviewed in rounds 3-5
- package/                         results_package_README.md (authoritative protocol description), results_tables.md and
                                   results_package_v6.md (all tables), runs_all.json (440 records with histories), figures/,
                                   verification_log_closed_form.txt, functional_parameter_audit.txt, family_equivalence_check.txt,
                                   e4_checkpoint_gains.md, selected_lrs.json, closed_form_appendix.md, code_bundle.txt

## Regeneration
The generators write to ../paper/results_package/ relative to analysis/ (created if absent); the delivered copies of
their outputs are under package/. make_code_bundle.sh uses the local analysis/ground_truth.py and stops with an error if
any input file is missing.

    cd analysis && python3 make_results_package.py && python3 make_runs_all.py && ./make_code_bundle.sh
    python3 ground_truth.py                      # exact-solution self-test
    OMP_NUM_THREADS=2 python3 family_equivalence.py
    python3 functional_count.py
